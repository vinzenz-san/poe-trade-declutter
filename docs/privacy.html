Privacy Policy

Last updated: 2026-08-20

PoE Trade Declutter is a browser extension (Firefox & Chrome) that lets you hide or reorder filter categories and stat filters, pick minimum stat tiers, and save searches as favorites, on the official Path of Exile trade site (pathofexile.com/trade). This policy explains what the extension accesses and why.

Summary

  • The extension does not operate its own server, does not use analytics, and does not transmit any of your data anywhere.
  • It does make one kind of outgoing network request: fetching publicly-published Path of Exile game-data files from RePoE (a third-party, community-maintained data mirror hosted on GitHub) to build the tier-picker's stat tables. This is a one-way read of public data — no information about you or your searches is sent as part of it.
  • Your preferences (which categories/filters you've marked hidden, tier-picker settings, saved favorite searches and their names) and the fetched RePoE tier data are stored only in your browser's local extension storage (browser.storage.local), via the standard storage permission. None of this leaves your device.
  • The extension only runs on pathofexile.com/trade pages. It does not run on, read, or access any other website.
  • The extension reads data already present on the trade page — its own filter definitions and your existing session settings, both stored by the Path of Exile trade site itself in your browser's localStorage — purely to know which categories and filters currently exist, so it can add show/hide and tier-picker controls next to them. Nothing read this way is copied, stored elsewhere, or sent off your device.
  • No account, sign-in, or personal information is required or collected.

Permissions

PermissionWhy it's needed
storage Saves your chosen hidden categories/filters and tier-picker settings locally so they persist between visits to the trade site, and caches the fetched RePoE tier data so it isn't re-downloaded on every page load.
Host access to pathofexile.com/trade* Required to inject the show/hide and tier-picker controls into the trade site's filter panel. The extension does not run on any other page.
Host access to raw.githubusercontent.com/brather1ng/RePoE/* Fetches RePoE's published Path of Exile stat/modifier data files, used to build the tier-picker's stat tables. Scoped to this one repository only, not all of raw.githubusercontent.com.

Third parties

PoE Trade Declutter is an independent, unofficial project and is not affiliated with or endorsed by Grinding Gear Games. It does not share your data with Grinding Gear Games, advertisers, or any other third party — it has no mechanism to do so. The one outgoing request it makes (to RePoE, described above) only downloads public game data; it does not upload anything about you.

Changes to this policy

If this policy changes, the "Last updated" date above will be revised and the change will be reflected in the extension's GitHub repository.
